Ghost Translation v5

APK on GitHub (free):
1. Make a new GitHub repository and upload ALL files of this folder (keep the .github folder).
2. Open the "Actions" tab -> "Build APK" -> Run workflow (it also runs on every push).
3. When it turns green, open the run and download "Ghost-Translation-APK" (app-debug.apk). Install it on the phone.

The web app lives in www/ (index.html). Open www/index.html in Chrome to test on a PC.
Voice in the APK uses the phone's own speech engine (Google). On the phone, make sure the Google app and
"Speech Services by Google" are installed and the Hindi voice is downloaded (Settings > Text-to-speech).
